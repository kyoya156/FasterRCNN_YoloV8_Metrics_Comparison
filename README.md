This is A 2015 faster RCNN architecture with a frozen backbone fine-tuned for 15 epochs vs a 2023 YOLOv8n(nano) architecture purpose-built for exactly this kind of task comparison 

This comparison reflects the state of each architecture as commonly 
deployed, not an exhaustive hyperparameter-matched benchmark. 
The performance gap is partly attributable to architectural advances 
made in the 8 years between publications, and should be interpreted 
in that context.

In short, this comparison is biased in many ways metric-wise. But still enough to see the metric differences.
